# Lingrow — Épicos & Sprints
**Horizonte:** 8 semanas (2 meses)
**Metodologia:** Scrum adaptado para fundador solo

---

## Como funciona o Scrum aqui

- **Sprint** = 1 semana de trabalho
- **Épico** = grande objetivo com várias tarefas
- **Story** = tarefa específica com critério de conclusão claro
- **Daily** = você responde mentalmente: "O que fiz? O que farei? Tem bloqueio?"
