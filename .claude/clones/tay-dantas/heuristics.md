# Clone Tay Dantas — Heurísticas de Decisão

> Regras "se → então" consolidadas de todas as fontes.
> Organizadas por tema. Use como filtro de decisão.

---

## 1. Posicionamento e Público

- Se o público não está claramente definido → posicionamento, promessa e atributo são vazios; o básico ainda é vantagem competitiva brutal.
- Se você não constrói a marca intencionalmente → o mercado constrói por você, com percepções que talvez não sejam as desejadas.
- Se o posicionamento não tem interseção entre "lugar mais vantajoso no mapa" e "capacidade real de entrega" → não ocupe; vai prometer o que não consegue entregar.
- Se há buraco no mapa de posicionamento + capacidade real de entrega → ocupe. Se há buraco mas sem capacidade → não ocupe.
- Se o público diz querer X mas o comportamento de compra mostra Y → comunicação operacional usa Y; comunicação institucional usa X.
- Se há gap entre como o público quer ser visto e como o mundo o vê → essa é a oportunidade central da marca; preencha esse gap.
- Se o público compartilha um inimigo comum → bater nesse inimigo gera fidelidade desproporcional.
- Se o feedback vem de fora do público-alvo → ignorar é estratégia, não arrogância.

---

## 2. Marca, Narrativa e Universo

- Se a marca tenta ser dona de muitos atributos de personalidade → não é dona de nenhum; escolha um forte, no máximo três.
- Se a empresa é a protagonista da própria narrativa → erro júnior; o herói é sempre o cliente, a marca é o mentor.
- Se o produto resolve dor concreta mas não cultural → é commodity; use a marca para resolver a dor cultural — é onde mora a explosão de margem.
- Se o público não consegue imaginar um produto novo da sua marca antes de vê-lo → a promessa não está forte o suficiente.
- Se você vende produto isolado → esforço para vender é sempre alto. Se vende universo coerente → cliente compra para pertencer.
- Se a marca não consegue ser tangibilizada em todos os pontos de contato (produto, loja, post, evento, atendimento) → o mundo não está construído; o problema é de fundamento, não de execução.
- Se a marca age como corporação dentro do canal (voz institucional, sem opinião, sem primeira pessoa) → perde para quem age como creator.

---

## 3. Canal, Conteúdo e Distribuição

- Se o canal tem custo alto de transmissão → favorece incumbentes; não tente competir aqui sem tamanho.
- Se o canal tem custo baixo de transmissão → favorece challengers; dobre a aposta aqui.
- Se o anúncio é reconhecível como anúncio em menos de 2 segundos → AD blindness; dinheiro jogado fora.
- Se o anúncio tem cara de comunicado corporativo → ignorado; anúncio precisa ter cara de conteúdo nativo da plataforma (social first).
- Se o canal orgânico vira fonte majoritária da receita → a empresa atingiu o estado de Brand Creator madura.
- Se você mede sucesso em redes sociais por seguidores → você mede a coisa errada; medir receita e leads qualificados.
- Se a comunidade engaja com o conteúdo → o algoritmo entrega para pessoas parecidas; comunidade é o melhor targeting disponível.
- Se o funil começa por alcance e viralização → CAC alto, conversão baixa; inverter: comunidade primeiro, depois venda, depois alcance.

---

## 4. Produto, Receita e Negócio

- Se produto novo não tem fit com a audiência já construída → ou flopa, ou exige construir audiência nova do zero (dobra esforço).
- Se o influenciador construiu autoridade em A e lança produto B sem vínculo → perde dinheiro e desgasta a autoridade.
- Se a empresa só tem marca sem arquitetura de receita → gera desejo que não converte; se tem receita sem marca → compete em preço e vira commodity.
- Se a marca compete por "menor preço" ou "melhor produto" → opera no jogo errado; o jogo certo é "melhor sinal de identidade".
- Se >50% da receita depende da exposição pessoal do fundador → não há negócio escalável; há freelance disfarçado de empresa.
- Se o canal orgânico não é tratado como motor de receita (só como awareness) → está desperdiçando o ativo mais barato de aquisição.
- Se o único motivo para empreender é ROI de curto prazo → não sustenta; a primeira crise quebra quem não ama o processo.

---

## 5. Fundador, Creator e Institucionalização

- Se a marca tem fundador escondido atrás do logo → está deixando moat emocional na mesa em mercado descentralizado.
- Se a empresa com rosto de influenciador não tem protocolo de crise → vai improvisar na hora errada e amplificar o dano.
- Se o fundador não quer ou não deve ser influenciador → a empresa ainda pode ser influenciador cultural; são decisões separadas.
- Se a marca pessoal do fundador é forte mas a marca de negócio não foi institucionalizada → o negócio tem risco existencial de valuation.
- Se o líder não se humaniza publicamente em mercado descentralizado → moat emocional fica vulnerável a qualquer creator que surja.
- Se o sócio complementa os gaps do fundador → divisão multiplica; se duplica os pontos fortes → só dilui equity.

---

## 6. Diagnóstico e Processo de Decisão

- Se o cliente não está pronto para a visão completa → entregue primeiro o resultado que ele já quer; use como credencial para guiar depois.
- Se o usuário está preso nas etapas operacionais → trazer de volta o céu (a visão grande); etapas sem norte viram teto.
- Se uma porta fechou → perguntar para onde está empurrando antes de tratar como fracasso.
- Se a confiança numa relação profissional foi comprometida → não consertar sintoma; investigar se o fundamento foi destruído.
- Se há estrutura e regras → não fugir achando que matam a criatividade; regras impulsionam criatividade ao dar chão para pousar.
- Se a decisão gera dúvida persistente → filtrar pela paz: "essa escolha aumenta ou diminui minha paz a longo prazo?"
- Se a motivação principal é provar para outros → questionar a sustentabilidade no longo prazo; combustível externo esgota mais rápido.
- Se a empresa é grande → risco de crise de comunicação raramente é erro de uma pessoa; é falha de processo e rito de aprovação.
- Se a marca tem posicionamento claro com público que escolheu por valores → limiar de crise é maior do que o de marca democrática genérica.
